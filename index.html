sen · cos · tan — Círculo Trigonométrico

📘 Aprende la lógica (no de memoria)

Todo sale del círculo unitario (radio = 1) y de dos triángulos especiales. Si entiendes estos 3 dibujos, los valores salen solos.

1) El círculo unitario

Tomas un punto sobre la circunferencia de radio 1, formando un ángulo θ con el eje X. Sus coordenadas son:

x = cos θ  ·  y = sen θ

Es decir:

  • sen θ = cuánto sube el punto (altura / cateto opuesto).
  • cos θ = cuánto avanza el punto (base / cateto contiguo).
  • tan θ = la inclinación = altura / base = sen θ / cos θ.

Aquí no hay que memorizar: si recuerdas que el radio mide 1, todo lo demás se lee del dibujo. Pruébalo en 🧪 Laboratorio.

2) Los dos triángulos especiales

De aquí salen TODOS los valores notables. (Recuerda SOH·CAH·TOA: sen = opuesta/hipotenusa, cos = contigua/hipotenusa, tan = opuesta/contigua.)

45–45–90 → lados 1, 1, √2
sen 45° = cos 45° = 1/√2 = √2/2
tan 45° = 1
30–60–90 → lados 1, √3, 2
sen 30° = 1/2 · sen 60° = √3/2
cos 30° = √3/2 · cos 60° = 1/2

3) El patrón √n/2 (truco de memoria)

Escribe el seno de 0°, 30°, 45°, 60°, 90° como √0/2, √1/2, √2/2, √3/2, √4/2:

θ0°30°45°60°90°
sen √0/2 = 0√1/2 = 1/2√2/2√3/2√4/2 = 1
cos 1√3/2√2/21/20
tan 0√3/31√3∄ (indef.)

El coseno es la misma fila al revés. La tangente es sen/cos.

4) El resto del círculo: solo cambian los SIGNOS

Para cualquier ángulo buscas su ángulo de referencia (el ángulo agudo que forma con el eje X) y usas los valores de la tabla. Después aplicas el signo según el cuadrante:

CuadranteRangosencostan
I0°–90°+++
II90°–180°+−−
III180°–270°−−+
IV270°–360°−+−

Truco en inglés: ASTC — “All Students Take Calculus”. En español: Todos (I) / Sen (II) / Tan (III) / Cos (IV).

Ejemplo: 150° está en el cuadrante II, su referencia es 30°. Entonces sen 150° = +1/2, cos 150° = −√3/2, tan 150° = −√3/3.

5) Grados ↔ radianes

Media vuelta = 180° = π radianes. Para convertir: multiplica por π/180 (a radianes) o por 180/π (a grados).

Los notables: 30°=π/6 · 45°=π/4 · 60°=π/3 · 90°=π/2 · 180°=π · 270°=3π/2 · 360°=2π.

📎 Bonus: teoremas del seno y del coseno

Se usan para resolver triángulos que no son rectángulos (a, b, c = lados; A, B, C = ángulos opuestos).

a / sen A = b / sen B = c / sen C

Teorema del seno: útil cuando conoces un lado y su ángulo opuesto.

a² = b² + c² − 2·b·c·cos A

Teorema del coseno: es el teorema de Pitágoras corregido cuando el ángulo no es 90° (si A = 90°, cos A = 0 y queda a² = b² + c²).
